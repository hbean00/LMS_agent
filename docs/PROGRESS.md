# 작업 기록

## 문제 정의 (2026-11-12 확정)

Canvas(고려대 mylms.korea.ac.kr 등) 과제 중 **이메일·종이로 내는 과제는 Canvas에 마감이 없다.** 마감은 공지·메시지·강의계획서·과제 설명에만 글로 적혀 있다.
학생이 휴대폰 캘린더 하나만 보고 무엇부터 할지 정할 수 있게, 그 글에서 **과제 단위**로 마감을 찾아 **근거 문장과 함께** 보여 주고, 승인한 것만 .ics로 내보낸다. 판단은 사람이 한다.
목표(/goal): 혼자 쓰는 도구가 아니라 **누구나 내려받아 자기 Canvas에 연결해 쓰는 배포 가능한 앱**.

완료 기준: ① 이메일 과제 마감이 근거와 함께 목록에 나온다 ② 승인한 것만 캘린더에 중복 없이 들어가 휴대폰에서 보인다 ③ 제출 여부 표시(Canvas 제출은 자동, 메일 제출은 직접 체크), 확인 못 한 것은 그렇게 표시.

## 구조 결정

- 표준 라이브러리만 쓰는 Python 패키지 → `pip install` 또는 PyInstaller exe 한 파일로 배포.
- 마감 찾기는 규칙 기반(AI 키 불필요, 결정적). 추정한 부분은 `notes`로 드러낸다.
- 역할 분리(JEDEC 구조를 코드로): 수집 `core.collect` / 정리 `core.build_items`(묶기·중복·연결·충돌·근거 없음) / 출력 `ics.build_ics` + 검사기 `ics.validate_ics`.
- Canvas 원본을 `state.json`의 cache에 두고 언제든 다시 만든다(`core.rebuild`) → 붙여넣기는 네트워크 없이 처리.
- 화면 서버는 127.0.0.1 전용, Host 검사 + 실행마다 바뀌는 세션 값(`X-LMS-Agent`)으로 다른 사이트의 요청을 막는다.
