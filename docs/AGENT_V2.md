# 에이전트 하네스 v2 설계 (2026-11-14, 사용자 결정 반영 — v0.8.0)

사용자: "대화가 잘 안 된다. 뭔가를 요청하면 일단 문서를 무조건 탐색한다", "잘못 기입된 일정·성적 제거를 요청했는데 다른 소리부터 한다",
"Assignment가 중복 등록된 것 같아 없애 줘를 요청해도 제거해 주지 않는다" → "AI가 먼저 판단하고 필요할 때 도구를 쓰는 방식으로 바꾸자. 설계부터".

## 1. 지금(v0.7.2)의 문제

| 문제 | 원인 |
|---|---|
| 무엇을 할지 규칙(낱말·정규식)이 정한다 | `agent.answer`가 actions → mail → plan → whatif → 잡담 낱말 → **문서 검색** 순으로 갈래를 고른다. AI는 이 판단에 끼지 못한다 |
| 기본 길이 '문서 검색' | 명령·잡담 패턴에 안 걸리면 거의 다 검색 → 인용 답(question) 또는 놓친 것 찾기(missing) |
| AI는 정해진 숙제를 한 번만 | 갈래 안에서 `answer`/`assist`/`chat` 중 하나를 JSON 한 번으로. 스스로 도구를 고르거나 여러 단계로 일하지 못한다 |
| **지우기·고치기 도구가 없다** | AI가 낼 수 있는 제안은 마감 추가·날짜 고치기·점수 연결·개수·비중·학점 비율·화면 동작뿐. 잘못 들어간 일정 삭제, 성적 지우기, 중복 평가 항목 합치기·지우기는 할 방법 자체가 없다 → "다른 소리"를 하게 됨 |
| 느리다 | 부를 때마다 CLI 프로세스를 새로 띄움(수십 초), 묻기당 2회·하루 30회 |

## 2. 새 구조: 도구를 쓰는 에이전트 루프 (AI가 켜져 있을 때)

```
메시지 + 이전 대화 + 지금 상태 요약(과목·마감·평가 항목, 모두 id 포함)
   │
   ▼
AI(한 번 부름) ── "바로 답" ─────────────────────────────▶ 답
   │
   └ "도구 쓸게" [{tool, args}…]
          │  읽기 도구 → 하네스가 바로 실행해 결과를 돌려줌
          │  바꾸기 도구 → 검증된 '제안' 카드(지금처럼 [실행]/[되돌리기])
          ▼
       AI(결과를 보고 다시) … 최대 3번
          ▼
         답 + 한 일 목록("공지 3개 찾아봄", "성적 계산함") + 제안 카드
```

- **AI가 먼저 판단**한다(낱말 갈래 없음). 인사·잡담·일반 질문은 도구 없이 바로 답한다.
- AI가 꺼져 있거나 한도를 넘거나 실패하면 지금의 규칙 갈래(v0.7.2)로 답한다.
- 매 단계 출력은 하나의 JSON: `{"say": "사용자에게 할 말(선택)", "calls": [{"tool", "args"}], "done": bool}`.

## 3. 도구

**읽기(바로 실행, 상태를 안 바꿈)**

| 도구 | 하는 일 |
|---|---|
| `search_texts(query, course_id?)` | 공지·게시판·메시지·강의계획서·첨부(PDF·표) 문단 검색(지금 `_search`) |
| `list_items(course_id?, status?, from?, to?)` | 마감·시험 목록(id·제목·날짜·상태·출처·중복/연결 관계) |
| `get_item(item_id)` | 항목 하나의 근거 사슬·결정 기록 |
| `get_grades(course_id)` | 평가 항목(id·이름·비중·출처)·점수·추정·학점 비율 |
| `whatif(course_id, question)` | 성적 '만약에' 계산(숫자는 앱이) |
| `list_materials(course_id?, category?)` | 받은 자료 목록 |
| `get_settings()` | 켜진 설정·연결 상태(토큰 없음) |

**바꾸기(제안만 만듦 → 사용자 [실행] → 되돌리기)** — 지금 것 + **새로 추가할 지우기·고치기**

| 도구 | 하는 일 | 되돌리기 |
|---|---|---|
| `propose_item_remove(item_id, reason)` **신규** | 잘못 들어간 마감·시험을 '제외'로(찾은 후보) 또는 지움(직접·AI가 넣은 것). Canvas 과제는 숨기기 | ○ |
| `propose_item_merge(keep_id, drop_id)` **신규** | 같은 과제로 보이는 두 항목을 하나로(중복 정리) | ○ |
| `propose_component_remove(course_id, name, merge_into?)` **신규** | 평가 항목 지우기·다른 항목에 합치기(예: 뜬금없이 생긴 'Assignment') | ○ |
| `propose_score_clear(course_id, component, which)` **신규** | 잘못 들어간 점수·잘못 연결된 점수 후보 떼기 | ○ |
| `propose_add_deadline` / `propose_fix_due` / `propose_link_score` / `propose_count` / `propose_weights` / `propose_dist` | 지금 assist 제안 그대로 | ○ |
| `propose_action(action, params)` | 화면 단추와 같은 동작(계약 22-9) | 동작마다 |
| `draft_mail(...)` / `make_plan(...)` | 메일 초안·공부 계획(지금 모듈) | — / ○ |

검증은 지금처럼 하네스가 한다: id가 실제로 있는지, 지울 대상의 제목·날짜를 카드에 그대로 보여 주는지, 근거 인용이 원문에 그대로 있는지, 숫자는 앱 계산인지.

## 4. AI에게 주는 것 / 주지 않는 것

- 준다: 사용자 메시지, 같은 대화의 최근 차례(가림), 앱이 할 수 있는 일, 상태 요약(과목·다가오는 마감·평가 항목 — id 포함, 성적은 사용자가 물었을 때 `get_grades`로만), 도구 결과.
- 주지 않는다: 토큰·비밀값, 다른 학생 정보(점수표는 내 값·반 집계만), 구글 캘린더 개인 일정(사용자가 켜기 전까지), 이메일·학번(지금처럼 가림).

## 5. 사용자 사례가 어떻게 바뀌나

| 요청 | 지금 | v2 |
|---|---|---|
| "잘못 들어간 기말고사 일정 지워줘" | 검색 → 엉뚱한 인용 | `list_items` → 해당 항목 찾기 → `propose_item_remove` 카드 "로봇공학개론 기말고사 12/15 10:30을 제외할게요" [실행] |
| "Assignment 중복 등록된 것 같아 없애줘" | 검색 → 못 함 | `get_grades`/`list_items` → 'Assignment'가 무엇인지 확인 → `propose_component_remove`(또는 `propose_item_merge`) [실행] |
| "안녕, 요즘 힘들다" | 낱말 맞으면 규칙 잡담 | 도구 없이 바로 대화 |
| "기말 몇 점 받아야 A?" | 낱말 맞으면 whatif | `whatif` 도구 → 계산 결과로 답 |

## 6. 한도·속도

- 묻기 한 번: AI 최대 3번(도구 왕복), 한 번 90초. 하루 한도 30 → (결정 필요) 100.
- 상태 요약을 처음부터 넉넉히 줘서 대부분 0~1번 왕복으로 끝나게 한다.
- 화면: 단계마다 "공지 검색 중… / 성적 계산 중…"을 보여 준다.

## 7. 사용자 결정 (2026-11-14)

- **실행 방식 = B**: "지워줘·고쳐줘"처럼 분명히 시킨 것 + 되돌릴 수 있는 변경은 하네스가 검증한 뒤 **바로 반영**하고 `decided_by: "ai"`·이유·[되돌리기]를 보여 준다.
  요청이 애매하거나(대상이 여럿·확신 낮음) 되돌릴 수 없는 것(업데이트 등)은 제안 카드로 묻는다.
- **하루 AI 한도 = 설정에서 고르기**: 기본 100, 30 / 100 / 300 / 제한 없음.
- **구글 캘린더 개인 일정 = AI에게 보내지 않음**(대시보드에만).
- **버전 = v0.7.3(엑셀 점수표) 먼저, 에이전트 v2는 v0.8.0.**

### (참고) 결정 전에 물었던 것

1. **바꾸기 실행 방식**: (A) 지금처럼 늘 [실행]을 눌러야 함 / (B) "지워줘"처럼 분명히 시킨 것 + 되돌릴 수 있는 것은 바로 하고 [되돌리기]를 보여 줌(CLAUDE.md의 'AI가 검증된 것만 decided_by: ai로 반영, 되돌릴 수 있게'와 맞음).
2. **하루 AI 한도**: 30 그대로 / 100 / 설정에서 고르기.
3. **구글 캘린더 개인 일정**을 AI가 볼 수 있게 할지(기본 안 봄).
4. **버전**: v0.7.3(엑셀 점수표 고침)을 먼저 내고 v0.8.0으로 에이전트 v2 — 권장.

## 8. 'Assignment' 중복 — 확인 필요

이 PC의 기본 데이터 폴더(v0.6.2, 11/13 동기화)에는 로봇공학개론에 Project1·Project2·Report·기말고사만 있고 'Assignment'가 없다.
쓰시는 앱은 다른 데이터 폴더(다른 PC 또는 다른 설치)로 보인다. 어느 화면(대시보드 / 확인함 / 성적의 평가 항목 / 과목 화면)에 보이는지 화면 캡처를 주시면 원인을 고친다.
v0.7.0~0.7.2에서 바뀐 것 중 후보: 과제 설명 링크 파일(0.7.2 — 그 PDF의 'Assignment' 문장을 평가 비중이나 마감으로 읽었을 가능성), 평가 항목 자동 채우기.
