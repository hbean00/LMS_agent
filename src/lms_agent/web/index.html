캘린더 파일 (.ics)

구글을 연결하지 않고 쓸 때의 방법이에요. 파일을 받아 캘린더 앱에 가져오세요.

파일을 받은 뒤 바뀐 일정이 있어요. 다시 받아서 가져오세요.

캘린더 파일 받기
구글 캘린더에 파일로 넣는 법
  1. 캘린더 파일 받기로 lms-deadlines.ics를 받아요.
  2. PC에서 calendar.google.com을 열어요. 휴대폰 앱에서는 파일을 가져올 수 없어요.
  3. 톱니바퀴 → 설정 → 가져오기/내보내기에서 받은 파일을 고르고, 넣을 캘린더를 선택한 뒤 가져오기.
  4. 가져온 일정은 저절로 바뀌지 않아요. 마감을 고쳤다면 다시 받아 가져오세요. 따로 만든 ‘LMS 마감’ 캘린더에 넣어 두면 지우고 다시 넣기 쉬워요.
