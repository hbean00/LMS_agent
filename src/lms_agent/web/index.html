직접 붙여넣기

Canvas 밖에서 받은 메일이나 PDF의 글을 붙여 넣으면 마감을 찾아 왼쪽 목록에 올립니다.

‘다음 주 금요일’처럼 적힌 날짜는 받은 날짜를 기준으로 계산합니다.

Canvas 연결

학교 Canvas 주소와 액세스 토큰을 넣으면 과제·공지·메시지를 읽어 학기 일정을 만듭니다.

브라우저로 Canvas에 들어갔을 때 주소창 맨 앞부분입니다.

받는 법: Canvas → 계정 → 설정 → 새 액세스 토큰 발급 → 나온 값을 복사해 붙여 넣기

토큰은 이 PC에만 저장되고 Canvas에 접속할 때만 씁니다. 읽기만 하며 메시지를 읽음으로 바꾸지 않습니다.

구글 캘린더

캘린더에 넣을 것

구글 캘린더와 캘린더 파일에 똑같이 적용됩니다. 찾은 마감은 승인한 것만 들어갑니다.

캘린더 파일 (.ics)

구글을 연결하지 않고 쓸 때의 방법입니다. 파일을 받아 캘린더 앱에 가져오세요.

파일을 받은 뒤 바뀐 일정이 있습니다. 다시 받아서 가져오세요.

캘린더 파일 받기
구글 캘린더에 파일로 넣는 법
  1. 캘린더 파일 받기로 lms-deadlines.ics를 받습니다.
  2. PC에서 calendar.google.com을 엽니다. 휴대폰 앱에서는 파일을 가져올 수 없습니다.
  3. 톱니바퀴 → 설정 → 가져오기/내보내기에서 받은 파일을 고르고, 넣을 캘린더를 선택한 뒤 가져오기.
  4. 가져온 일정은 저절로 바뀌지 않습니다. 마감을 고쳤다면 다시 받아 가져오세요. 따로 만든 ‘LMS 마감’ 캘린더에 넣어 두면 지우고 다시 넣기 쉽습니다.
