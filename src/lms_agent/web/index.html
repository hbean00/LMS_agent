Canvas 연결

학교 Canvas 주소와 액세스 토큰을 넣으면 과제·공지·메시지를 읽어 학기 일정을 만듭니다.

브라우저로 Canvas에 들어갔을 때 주소창 맨 앞부분입니다.

받는 법: Canvas → 계정 → 설정 → 새 액세스 토큰 발급 → 나온 값을 복사해 붙여 넣기

토큰은 이 PC에만 저장되고 Canvas에 접속할 때만 씁니다. 읽기만 하며 메시지를 읽음으로 바꾸지 않습니다.

캘린더 파일

캘린더 파일 받기

휴대폰 캘린더에 넣는 법

  1. 캘린더 파일 받기를 눌러 lms-deadlines.ics 파일을 받습니다.
  2. PC에서 calendar.google.com을 엽니다. 휴대폰 앱에서는 파일을 가져올 수 없습니다.
  3. 오른쪽 위 톱니바퀴 → 설정 → 왼쪽 메뉴의 가져오기/내보내기.
  4. 컴퓨터에서 파일 선택으로 받은 파일을 고르고, 넣을 캘린더를 선택한 뒤 가져오기.
  5. 잠시 뒤 휴대폰 Google 캘린더 앱에도 나타납니다.

바뀌면 다시 가져와야 합니다. 가져온 일정은 저절로 바뀌지 않습니다. 마감을 새로 넣거나 고쳤다면 파일을 다시 받아 가져오세요.

다시 가져올 때 Google이 같은 일정을 알아보고 덮어쓰는지(UID 기준 중복 제거)는 아직 확인하지 못했습니다. 그래서 ‘LMS 마감’ 같은 별도 캘린더에 가져오기를 권합니다(설정 → 캘린더 추가 → 새 캘린더 만들기). 다시 가져올 땐 그 캘린더를 지우고 새로 만든 뒤 가져오면 일정이 두 번 생기지 않습니다.
